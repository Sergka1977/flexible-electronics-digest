# Гибкий слой — дайджест гибкой электроники

Адаптивный сайт-дайджест о гибкой и печатной электронике, носимых сенсорах и новых материалах. Собран на Flask, HTML, CSS и чистом JavaScript без тяжёлых фреймворков и сборки.

В первом выпуске — **11 реальных публикаций** за период **9 октября — 9 ноября 2026 года**. У каждой карточки есть русский заголовок и описание, источник, дата публикации, темы и прямая ссылка на первоисточник.

На главной странице есть кнопка **«Обновить подборку»** с красным ободком. Она заменяет карточки на другой проверенный набор из 10 публикаций за тот же период и по тем же темам. Повторное нажатие возвращает исходный выпуск.

## Быстрый запуск

Требования: Python 3.10+ (проверено на Python 3.12.10) и Flask 3.1.3.

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

macOS / Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:5000>.

Если виртуальное окружение не нужно, достаточно:

```bash
pip install -r requirements.txt
python app.py
```

Сервер запускается в режиме отладки на `127.0.0.1:5000`.

### Фильтры

| Фильтр | slug | Что показывает |
| --- | --- | --- |
| Все | `all` | Все 11 материалов |
| Гибкая электроника | `flexible` | Гибкие и растягиваемые устройства |
| Печатная электроника | `printed` | Чернила, печать, масштабируемые процессы |
| Носимые сенсоры | `wearable` | Датчики на теле и в одежде |
| Материалы | `materials` | Гидрогели, MXene, жидкие металлы, перовскиты |
| Гибкие дисплеи | `displays` | Сгибаемые дисплеи и экраны на гибкой подложке |
| Медицина | `medicine` | Диагностика и мониторинг здоровья |
| Вакансии | `jobs` | Проверенные вакансии; в этом выпуске — честное пустое состояние |

В тему «Гибкие дисплеи» попадают публикации о дисплеях, которые сгибаются, складываются или растягиваются, а также об экранах, изготовленных на гибкой полимерной, металлической или бумажной подложке. Обычные жёсткие LCD/OLED-панели в эту тему не включаются.

Фильтрация работает на клиенте: карточки скрываются по атрибуту `data-topics`, счётчики в кнопках формируются на сервере. Если в текущем выпуске нет материалов по теме, показывается пустое состояние с предложением вернуться ко всем публикациям. При выборе «Вакансии» показывается отдельное пустое состояние со ссылками на карьерные страницы TNO, imec и Imperial College London.

После обновления подборки счётчики фильтров, число публикаций в hero-блоке, бейдж полноты и полоса источников пересчитываются по новому набору. Активный фильтр сбрасывается на «Все».

## Как обновить новости

Все материалы хранятся в `data/news.json`. Сервер читает файл при каждом запросе, поэтому перезапуск после правок не обязателен — достаточно обновить страницу.

### 1. Метаданные выпуска

```json
"meta": {
  "site_name": "Гибкий слой",
  "tagline": "Дайджест гибкой электроники",
  "edition": "Выпуск № 1",
  "period_start": "2026-10-09",
  "period_end": "2026-11-09",
  "compiled_at": "2026-11-10",
  "target_count": 11,
  "vacancy_note": "…",
  "vacancy_links": []
}
```

- `period_start` / `period_end` — окно выпуска в формате `YYYY-MM-DD`.
- `target_count` — ожидаемое число карточек (сейчас 11).
- `compiled_at` — дата сборки выпуска.
- `vacancy_links` — массив объектов `{ "label": "…", "url": "…" }` для пустого состояния вакансий.

### 2. Карточка новости

```json
{
  "id": "уникальный-id",
  "order": 1,
  "title": "Русский заголовок",
  "summary": "Русское описание: что сделано, какие цифры, чем результат важен.",
  "source": "Название организации или журнала",
  "via": "Публикация-посредник (можно оставить пустым)",
  "date": "2026-10-29",
  "topics": ["wearable", "medicine"],
  "tags": ["Носимые сенсоры", "Медицина"],
  "url": "https://…",
  "reading_time": 5,
  "visual": "MOTION",
  "tone": "cyan"
}
```

Правила:

- `date` — дата публикации новости, а не дата исследования. Она должна попадать в окно выпуска.
- `topics` — массив slug’ов из блока `filters` (кроме `all` и `jobs`).
- `url` — только прямой проверяемый адрес первоисточника.
- `tone` — один из вариантов оформления: `cyan`, `blue`, `teal`, `indigo`.
- `visual` — короткая подпись на декоративной панели карточки.
- `reading_time` — целое число минут.

### 3. Фильтры и организации

Фильтры задаются в массиве `filters` (`slug`, `label`, `description`). Счётчики рассчитываются автоматически в `app.py`.

Организации задаются в массиве `organizations`: `name`, `short`, `focus`, `country`, `url`.

### 4. Альтернативная подборка

Кнопка «Обновить подборку» берёт второй набор из блока `refresh` в `data/news.json`:

```json
"refresh": {
  "target_count": 10,
  "items": [
    {
      "id": "уникальный-id",
      "order": 1,
      "title": "…",
      "summary": "…",
      "source": "…",
      "via": "Bioengineer.org",
      "date": "2026-11-08",
      "topics": ["wearable", "materials"],
      "tags": ["…"],
      "url": "https://…",
      "reading_time": 4,
      "visual": "SWEAT",
      "tone": "blue"
    }
  ]
}
```

Поля карточки те же, что и в основном выпуске. Сервер проверяет даты и полноту отдельно для каждого набора: для `refresh` используется собственный `target_count`.

После нажатия кнопки JavaScript запрашивает `GET /api/refresh?batch=2`, заменяет карточки, пересчитывает счётчики фильтров, обновляет число публикаций в hero-блоке, бейдж полноты и полосу источников, сбрасывает фильтр на «Все» и объявляет результат в `aria-live`. Повторное нажатие возвращает исходный выпуск (`batch=1`).

### 5. Проверка полноты

`app.py` проверяет:

- число карточек совпадает с `target_count`;
- все даты входят в `period_start`…`period_end`.

Если условие не выполнено, на странице появляется заметное предупреждение «Список неполный». Это сделано намеренно: лучше показать меньше материалов, чем добавить неподтверждённую карточку.

Служебная проверка доступна по адресу:

```text
GET /health
```

Пример ответа:

```json
{
  "ok": true,
  "items": 11,
  "complete": true,
  "dates_in_window": true,
  "refresh_items": 10,
  "refresh_complete": true,
  "refresh_dates_in_window": true
}
```

## API обновления подборки

```text
GET /api/refresh?batch=1|2
```

- `batch=1` — исходный выпуск из 11 карточек;
- `batch=2` — альтернативный набор из 10 карточек (используется по умолчанию, если параметр не указан);
- любое другое значение возвращает `400`.

Пример ответа (сокращённо):

```json
{
  "ok": true,
  "batch": 2,
  "next_batch": 1,
  "target_count": 10,
  "is_complete": true,
  "dates_in_window": true,
  "period_display": "9 октября — 9 ноября 2026",
  "counts": {
    "all": 10,
    "flexible": 10,
    "printed": 3,
    "wearable": 7,
    "materials": 8,
    "displays": 1,
    "medicine": 3,
    "jobs": 0
  },
  "stats": { "items": 10, "topics": 7, "days": 32, "days_label": "дня" },
  "sources": ["Frontiers in Chemistry", "Discover Sensors", "…"],
  "items": [{ "id": "…", "number": 1, "date_display": "9 ноября 2026", "…": "…" }]
}
```

`items` содержит те же поля, что и карточки в `data/news.json`, плюс `date_display` и `number`. Начальная страница по-прежнему рендерится на сервере с `batch=1`; JavaScript использует эндпоинт только при нажатии кнопки.

## Подписка (демо)

Форма отправляет `POST /api/subscribe` с JSON `{ "email": "you@example.com" }`.

- Адрес проверяется регулярным выражением и ограничением длины.
- При успехе email сохраняется в `data/subscribers.json`.
- Рассылка **не отправляется**: это честно указано в интерфейсе.
- Файл создаётся при первой успешной подписке; повторная запись не дублируется.

Эндпоинт принимает также обычную HTML-форму (`application/x-www-form-urlencoded`).

Ответы:

```json
{ "ok": true, "message": "Готово! Адрес сохранён. Это демо-режим…" }
```

```json
{ "ok": false, "message": "Проверьте формат email и попробуйте ещё раз." }
```

`subscribers.json` не следует коммитить в публичный репозиторий, если в нём есть реальные адреса.

## Доступность и адаптивность

- Семантические ориентиры, `skip-link`, видимый `:focus-visible`.
- Мобильное меню с `aria-expanded`, закрытием по `Escape` и возвратом фокуса.
- Фильтры — кнопки с `aria-pressed` и текстовым статусом в `aria-live`.
- Кнопка «Обновить подборку» — обычная кнопка с доступным именем, состоянием `aria-busy` во время запроса и видимым фокусом.
- Результат обновления объявляется в отдельном `aria-live`-регионе; ошибки запроса также выводятся текстом.
- Поддержка `prefers-reduced-motion`: анимации отключаются.
- Режим `forced-colors` для систем высокой контрастности.
- Контраст текста и элементов управления рассчитан на светлый фон.
- Темы обозначены не только цветом: у каждой карточки есть текстовые теги.
- На мобильных нет горизонтальной прокрутки; сетки перестраиваются в одну колонку.

## Технические детали

- `app.py` сортирует карточки по дате (новые выше), форматирует даты и период по-русски, считает счётчики фильтров отдельно для основного и альтернативного набора.
- Шаблон получает `items`, `filters`, `counts`, `sources`, `organizations`, `stats`, `vacancy_links`, `is_complete`, `dates_in_window`, `target_count`, `batch`.
- `GET /api/refresh?batch=1|2` возвращает готовые карточки с `date_display` и `number`, счётчики, источники и статистику.
- `static/js/main.js` создаёт карточки через DOM API, а не через вставку HTML-строк.
- Статика отдаётся Flask из `static/`.
- Внешние ссылки открываются в новой вкладке с `rel="noopener noreferrer"`.
- Полные тексты научных статей могут требовать подписки на стороне издателя.

## Возможные проблемы

**`ModuleNotFoundError: No module named 'flask'`** — не активировано виртуальное окружение или не установлены зависимости. Выполните `pip install -r requirements.txt`.

**Порт 5000 занят** — измените порт в конце `app.py`:

```python
app.run(host="127.0.0.1", port=5001, debug=True)
```

**На странице предупреждение «Список неполный»** — проверьте `target_count` и даты в `data/news.json`, затем откройте `/health`.

**Кнопка «Обновить подборку» показывает ошибку** — проверьте, что сервер запущен, и откройте `/api/refresh?batch=2` в браузере. Эндпоинт должен вернуть `ok: true` и 10 карточек.

**Ссылка на science.org не открывается автоматически** — сайт издателя блокирует часть ботов; в обычном браузере ссылка DOI работает. Метаданные статьи проверены через Crossref.
