# Гибкий слой — дайджест гибкой электроники

Адаптивный сайт-дайджест о гибкой и печатной электронике, носимых сенсорах и новых материалах. Собран на Flask, HTML, CSS и чистом JavaScript без тяжёлых фреймворков и сборки.

Выпуск — **10 проверенных публикаций** с русскими заголовками и описаниями из `data/news.json`. И начальная страница, и поиск новостей всегда используют одно окно: **сегодня минус один календарный месяц … сегодня**, вычисляемое на каждый запрос без зашитых дат. Кнопка **«Обновить подборку»** не переключает готовые наборы: она выполняет новый поиск по тегу, который выбран в интерфейсе в момент нажатия, и собирает до 10 материалов из реальных открытых источников в этом же окне. Уже показанные этому посетителю материалы не повторяются.

## Быстрый запуск

Требования: Python 3.10+ (проверено на Python 3.12.10) и Flask 3.1.3.

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

macOS / Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:5000>. Если виртуальное окружение не нужно, достаточно `pip install -r requirements.txt` и `python app.py`.

Сервер запускается в режиме отладки на `127.0.0.1:5000`.

## Развёртывание на Render Free

В репозитории есть `render.yaml`, поэтому сервис можно создать как Blueprint. Команды также подойдут для ручной настройки:

- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `gunicorn --bind 0.0.0.0:$PORT app:app`
- **Plan:** Free
- **Health Check Path:** `/health`

`PORT` и `0.0.0.0` обязательны: Render передаёт порт через переменную `PORT`, а привязка только к `127.0.0.1` делает сервис недоступным извне. Gunicorn импортирует модуль `app`, поэтому локальный `app.run(...)` при развёртывании не выполняется.

Подписка работает в демонстрационном режиме: адреса никуда не записываются. История обновлений хранится в JSON-файле; на Free-плане файловая система временная, поэтому после перезапуска/переезда инстанса история может потеряться. Для надёжного хранения подключите постоянный том или общую базу и задайте `DIGEST_HISTORY_FILE`.

## Как работает обновление

1. Клиент читает активную кнопку `.filter-btn[aria-pressed="true"]` и отправляет её `data-filter` в `/api/refresh?tag=…`. После ответа тот же тег остаётся активным.
2. Сервер заново вычисляет скользящий период: `date.today() - 1 календарный месяц … date.today()`. Даты не зашиты в код; конец месяца обрабатывается корректно (например, 31 марта → 28/29 февраля).
3. Для выбранного тега используются свои поисковые формулировки; для «Все» — формулировки всех тематик. Параллельно опрашиваются подключённые источники. Ошибка одного не блокирует остальные.
4. Кандидаты дедуплируются по каноническому URL (DOI/arXiv-версии нормализуются); если URL нет — по нормализованному заголовку. Затем проверяется соответствие теме по заголовку **и** абстракту из метаданных — одного похожего слова в заголовке недостаточно.
5. Для «Все» 10 материалов выбираются случайно с чередованием тем. Для конкретного тега берутся только подходящие материалы, для TFT дополнительно сохраняется приоритет релевантности 0 → 1 → 2. Для «Вакансий» используются только вакансии с датой, ссылкой и подтверждённой связью с тематикой сайта.
6. Если найдено меньше 10, выполняется дополнительный поиск в тех же источниках и периоде с другими формулировками. Если и после этого мало — показываются только найденные подходящие материалы и выводится сообщение, что их меньше десяти. Неподходящие и уже показанные записи не добавляются.
7. История посетителя обновляется **только при успешной выдаче** карточек. Если новых нет или все источники недоступны, текущие карточки остаются на месте, а пользователь видит понятное сообщение.
8. Клиент показывает состояние ожидания, блокирует повторные нажатия во время запроса (`refreshInFlight`) и обновляет зависящие от новостей показатели только после успешного ответа.

### Подключённые источники

| Источник | Что берётся | Ограничение |
| --- | --- | --- |
| [Crossref](https://www.crossref.org/) | Метаданные journal-article, дата `published` / `published-online` / `published-print`, DOI, журнал, абстракт | Не все записи имеют полную дату и абстракт; возможны лимиты запросов |
| [OpenAlex](https://openalex.org/) | Статьи типа `article`, `publication_date`, DOI, журнал, инвертированный абстракт | Ключ необязателен, но без ключа общий лимит ниже; часть абстрактов отсутствует |
| [arXiv API](https://info.arxiv.org/help/api/index.html) | Свежие препринты по темам выпуска, дата отправки | Только препринты, не обязательно рецензированные; нет полноценных новостных лент |
| [Remotive API](https://remotive.com/api/remote-jobs) | Вакансии: название, работодатель, дата публикации, описание, прямая ссылка | Только удалённые вакансии; поиск по тематике часто даёт 0 совпадений |
| [Arbeitnow API](https://www.arbeitnow.com/api/job-board-api) | Вакансии: название, компания, UNIX-дата создания, описание, ссылка | Нет поискового параметра в публичном методе; релевантность проверяется локально |

Пять источников — открытые публичные API без обязательных секретов. Первые три используются для публикаций, два последних — только для тега «Вакансии». Сайт **не охватывает все новости и вакансии в интернете**: он показывает только то, что доступно через эти API и попало в скользящий период. Заголовки и абстракты берутся из метаданных как есть (в основном на английском), без генерации или перевода, чтобы не добавлять выдуманные формулировки.

### Тег TFT matrixes

Для тега `tft` в три источника публикаций добавлены запросы `flexible thin film transistor backplane` и `TFT array display IGZO`; при дополнительном поиске — `TFT backplane active matrix display` и `oxide IGZO thin film transistor circuit`. Учитываются также русскоязычные формулировки в метаданных.

Отбор идёт по трем уровням релевантности:

1. **0** — в заголовке одновременно есть TFT-матрица/backplane/транзистор и гибкая подложка или гибкий дисплей. Такие материалы идут первыми.
2. **1** — TFT-матрица для LCD/OLED/AMOLED/MicroLED/электронной бумаги или активная матричная подсветка без гибкой подложки.
3. **2** — материалы и технологии TFT (IGZO, LTPS, оксидные полупроводники, аморфный кремний, органические полупроводники, печать, лазерный перенос, roll-to-roll), если в метаданных нет подтверждённой готовой матрицы. У таких карточек показывается пояснение «Косвенная связь» с причиной отнесения к тегу.

Общие новости о телевизорах, LED-подсветке без матричного управления и гибких экранах без упоминания TFT/backplane не попадают в тег. Дата публикации, первоисточник и связь с темой проверяются по метаданным источника; факты не добавляются от себя.

### История посетителя

Учётных записей в проекте нет. Каждому браузеру выставляется устойчивый cookie `digest_vid` (HttpOnly, SameSite=Lax, 1 год). Сама история хранится не в памяти процесса, а в файле `data/visitor_history.json` на сервере (путь можно изменить через `DIGEST_HISTORY_FILE`). Запись идёт атомарно через временный файл и `os.replace`; ограничение размера — 200 последних ключей на посетителя.

Исходные 10 карточек тоже записываются в историю при первой загрузке страницы, чтобы первое обновление не вернуло их повторно.

### Настройки

Скопируйте `.env.example` в `.env` при необходимости. Переменные читаются из окружения; секреты не хранятся в исходном коде.

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `CROSSREF_MAILTO` | Контакт для Crossref (вежливый пул) | пусто |

## API

### Обновление подборки

```text
GET /api/refresh?tag=printed
```

`tag` — slug активного фильтра (`all`, `flexible`, `printed`, `wearable`, `materials`, `displays`, `tft`, `medicine`, `jobs`). Неизвестное значение трактуется как `all`. Параметр `batch` больше не поддерживается. Успешный ответ:

```json
{
  "ok": true,
  "mode": "live",
  "active_tag": "printed",
  "tag_label": "Печатная электроника",
  "target_count": 10,
  "is_complete": true,
  "shortfall": false,
  "dates_in_window": true,
  "period_display": "18 октября — 18 ноября 2026",
  "counts": { "all": 10, "flexible": 2, "printed": 10, "wearable": 2, "materials": 6, "displays": 1, "tft": 0, "medicine": 1, "jobs": 0 },
  "stats": { "items": 10, "topics": 7, "days": 32, "days_label": "дня" },
  "sources": ["Crossref", "OpenAlex", "arXiv"],
  "items": [{ "id": "…", "number": 1, "date_display": "18 ноября 2026", "…": "…" }],
  "message": "Подборка обновлена: 10 новых публикаций по тегу «Печатная электроника» за период …",
  "errors": []
}
```

Если подходящих материалов меньше десяти, ответ остаётся успешным, но `shortfall` равен `true`, а `message` прямо сообщает, что найдено меньше 10 и список не дополнялся неподходящими записями.

Если новых материалов нет:

```json
{ "ok": false, "reason": "no_new_items", "message": "…", "kept_current": true, "active_tag": "printed", "errors": [] }
```

Если недоступны все источники:

```json
{ "ok": false, "reason": "source_unavailable", "message": "…", "kept_current": true, "active_tag": "all", "errors": ["Crossref: TimeoutError"] }
```

В обоих случаях статус ответа для `no_new_items` — `200`, для `source_unavailable` — `503`; карточки на странице не заменяются.

### Служебная проверка

```text
GET /health
```

Возвращает состояние исходного выпуска, legacy-данные альтернативного набора, текущий скользящий период, список источников публикаций (`live_sources`), список источников вакансий (`vacancy_sources`) и путь к файлу истории. Поле `mode` всегда `"live"`.

### Подписка

`POST /api/subscribe` — демонстрационный endpoint: проверяет email и возвращает сообщение, что адрес не сохраняется и рассылка не подключена.

## Данные выпуска

`data/news.json` содержит метаданные, фильтры, организации, 10 карточек выпуска и legacy-блок `refresh`, который используется только для обратной совместимости `/health`. Кнопка обновления этот файл не читает и не меняет.

Сервер читает файл при каждом запросе, поэтому после ручных правок исходного выпуска перезапуск не требуется — достаточно обновить страницу.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты покрывают:

- пересчёт календарного периода, включая конец месяца и високосный год;
- канонизацию DOI, URL, arXiv-версий и заголовков без URL;
- исключение старых, уже показанных и дублирующихся материалов;
- несколько последовательных обновлений без повторов;
- исчерпание новых материалов без подстановки старых;
- отказ источника без стирания текущей подборки;
- разделение истории разных анонимных посетителей;
- приоритеты релевантности TFT matrixes, исключение общих новостей о дисплеях и подсветке, пояснение косвенных совпадений;
- выбор активного тега из запроса, фильтрацию по содержанию, случайное чередование тем для «Все», ограничение в 10 материалов;
- дополнительный поиск при нехватке результатов и сообщение о количестве меньше 10;
- подбор вакансий вместо новостей и запрет подставлять обычные публикации в тег «Вакансии».

## Доступность

- Семантические ориентиры, `skip-link`, видимый `:focus-visible`.
- Мобильное меню с `aria-expanded`, закрытием по `Escape` и возвратом фокуса.
- Фильтры — кнопки с `aria-pressed` и текстовым статусом в `aria-live`.
- Кнопка обновления сохраняет состояния `aria-busy` и `disabled` во время запроса; результат и ошибки объявляются в `aria-live`.
- Поддержка `prefers-reduced-motion` и режима `forced-colors`.
- Темы обозначены не только цветом: у карточек есть текстовые теги.
- На мобильных нет горизонтальной прокрутки; сетки перестраиваются в одну колонку.

## Возможные проблемы

**`ModuleNotFoundError: No module named 'flask'`** — активируйте виртуальное окружение и выполните `pip install -r requirements.txt`.

**Порт 5000 занят** — измените порт в конце `app.py`, например на `5001`.

**«Источники новостей временно недоступны»** — проверьте интернет, `/health` и таймаут `NEWS_SOURCE_TIMEOUT`. Текущие карточки при этом сохраняются.

**«Новых публикаций за последний месяц не осталось»** — это нормально после нескольких обновлений: источники вернули только уже показанные материалы. История хранится в `data/visitor_history.json`; удаление файла сбросит историю всех посетителей.

**«Найдено меньше 10 …»** — в каждом теге может не набраться десяти релевантных материалов за месяц. Дополнительный поиск уже выполнен; список не дополняется неподходящими или уже показанными записями. Особенно часто это происходит в теге «Вакансии»: открытые API дают единицы вакансий, содержательно связанных с гибкой электроникой.

**История теряется после перезапуска** — на Render Free файловая система временная. Укажите `DIGEST_HISTORY_FILE` на постоянный том или подключите общую базу.

## Лицензия и статус

«Гибкий слой» — независимый демонстрационный дайджест, не научная публикация. Права на исходные материалы принадлежат их авторам и издателям. Сайт не претендует на полноту литературного обзора и не обещает охват всех новостей: доступны только публикации из подключённых источников за скользящий период.
